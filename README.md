# Hisaab Diary

Offline udhaar / lena-dena khata app for Android.

- Package: `com.hisaab.diary`
- Stack: Kotlin, Jetpack Compose, Material 3, MVVM + Clean Architecture, Hilt, Room, Coroutines/Flow, WorkManager
- 100% offline: no internet permission, no account, no cloud

Current state: starter source only (Hello World). There are no Gradle files yet. Phase 0 in `PLAN.md` adds them.

For the AI agent (Codex): read `AGENTS.md` first, then work through `PLAN.md` step by step.
